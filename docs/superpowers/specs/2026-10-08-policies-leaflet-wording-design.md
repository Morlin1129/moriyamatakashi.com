# 取り組みの文言をリーフレットに揃える 設計

日付: 2026-10-08

## 目的

政治活動リーフレット（B4二つ折り、初稿）の「取り組みたい5つのテーマ」を基準にして、取り組みのトップ・一覧・詳細の文言を揃える。トップと一覧はリーフレットの文言だけにし、余分な文言は消す。詳細ページの本文（課題・提案・確かめたいこと・目指す姿）はこのままにし、リライトは別の機会にする。

## リーフレットの5つのテーマ

| 番号 | id | 前置き | 見出し | 一文 |
|---|---|---|---|---|
| 01 | city-hall | | もっと力を発揮できる市役所へ | 市民に向き合える時間を、もっと増やします |
| 02 | odaka-kashima | 小高も鹿島も、もちろん原町のことも | 地域ごとの課題を、ちゃんと前へ | 「なぜこうなったの？」が分かる進め方にします |
| 03 | children | | もっと子育てしたいと思えるまちへ | 日々の生活で感じる「こうなったらいいのに」を形にします |
| 04 | economy | | 地元の会社が育つまちへ | 「ここで働きたい」と思える仕事を、地域に増やします |
| 05 | future | | 将来も豊かさが続くまちへ | 10年後・20年後のお金のことがもっとわかるようにします |

並び順はリーフレットの番号に合わせる（これまでは 市役所→子育て→会社→小高・鹿島→将来 だった）。`odaka-kashima` の URL とファイル名は、公開済みのリンクを変えないためそのままにする。本文は小高・鹿島に絞った内容のままなので、見出し「地域ごとの課題」より狭い。リライトのときに合わせる。

## frontmatter（`src/content.config.ts`）

| 項目 | 内容 | 使う場所 |
|---|---|---|
| `order` | リーフレットの番号 | 並び順、「取り組み 01」の表示 |
| `pretitle` | 見出しの上に添える一文（任意） | トップ、一覧、詳細のヒーロー |
| `title` / `titleLines` | 見出し。`titleLines` は改行位置で分けたもの | トップ、一覧、詳細の見出し、パンくず、資料集のチップ、前後ページのリンク、`<title>` |
| `lead` | 見出しの下の一文 | トップ、一覧、詳細のヒーロー、`description` |
| `summary` | リーフレットの本文。空行で段落を分ける | 詳細の冒頭「概要」、一覧の抜粋（先頭80文字＋「…」） |
| `image` / `resources` | 変更なし | |

`badge` `plain` `policyName` は消す。`badge` を使っていたパンくず・資料集のチップは `title` にする。

## 表示

- トップ（`src/components/home/Policies.astro`）: 見出しをリーフレットの「「こうなったらいいな」を、ひとつずつ実現するために」＋「取り組みたい5つのテーマがあります。」にする。各項目は 番号・（前置き）・見出し・一文・写真。
- 一覧（`src/pages/policies/index.astro`）: 各カードは 番号・（前置き）・見出し・一文（太め）・本文の抜粋・写真。抜粋は `src/lib/excerpt.mjs`（改行を除いて先頭80文字、超えたら「…」）。ページの見出しは「取り組みたい、5つのテーマ」、リードはリーフレットの一文。
- 詳細（`src/pages/policies/[id].astro`）: ヒーローは「取り組み 01」の札・（前置き）・見出し・一文。本文の先頭に `## 概要` の section を置き、`summary` を段落で載せる（段落内の改行は PC 表示でだけ `<br>`）。目次の先頭にも「概要」を足す。以降の本文（Markdown）はそのまま。
- 資料集（`src/pages/resources/sources.astro`）: チップとタグを `title` にする。

## 確認

- `npm test`（`excerpt` のテストを含む）と `npm run build` が通る。
- プレビューでトップ・一覧・詳細5ページ・資料集を見る。

## やらないこと

- 詳細ページの本文（課題・提案・確かめたいこと・目指す姿）のリライト。
- `odaka-kashima` の URL 変更。
