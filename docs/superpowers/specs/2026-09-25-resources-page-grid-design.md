# 「資料と数字」ページのカード化と「まちを知る」への改名 設計書

作成日: 2026-09-25

## 目的

「資料と数字」ページは、資料集（絞り込みチップ付きの一覧）が大きな面積を占め、ミニアプリ3本がその下に縦に並んでいる。資料集を「コンテンツの1つ」に格下げし、ミニアプリと同じ大きさのカードとして横並びに見せる。あわせてメニュー名を「まちを知る」に変える。

## 変更点

### 1. メニュー名

- `src/data/site.ts` の NAV ラベル「資料と数字」を「まちを知る」にする。href は `/resources/` のまま。
- ミニアプリ3ページ（tax / health / odaka）のパンくずは、文字をベタ書きせず NAV の resources 項目から label と href を引く。
- トップの「数字や資料で見る →」は文言もリンクもそのまま。

### 2. /resources/ の構成

- ヒーロー: バッジ「まちを知る」、見出し「資料と数字から、まちを考える。」（現状維持）、リード文は現状維持。右のアートも現状の「資料ノート」を維持。
- 本文: 導入の1段落（「選挙や政策を考える参考材料として…」の現行文）と、カード4枚のグリッド。目次は外す。
- カードの順: 税金はどこへ行った？ ／ まちの健康診断 ／ 小高 復興のあゆみ ／ 資料集。
- カードは縦型（上にアート、下に題名・説明・出典・ボタン）。PC は 2 列、スマホは 1 列。
- 4枚の内容は `src/data/tools.ts` に配列として持ち、`src/components/ToolCard.astro` で描画する。追加は配列に1件足すだけで済むようにする。
- 資料集カード: 既存の「紙」アートを流用。説明は「政策の根拠にしている市の計画・統計・議会資料を、取り組みごとに絞り込んで探せます。」の趣旨。ボタンは「資料を探す →」で `/resources/sources/` へ。

### 3. /resources/sources/ の新設

- ファイルは `src/pages/resources/sources.astro`。
- パンくず: トップ ／ まちを知る ／ 資料集。
- 内容は現行の「資料集で目指すこと」と「資料を探す」（絞り込みチップ + ResourceCards）をそのまま移す。目次は2節だけなので付けない。
- ヒーローは簡略版（バッジ「資料集」、見出し「資料を探す」、リード文「取り組みを考えるうえで参照している南相馬市の公開資料です。」）。

### 4. リンク修正

- `src/pages/policies/[id].astro` と `src/pages/apps/health.astro` にある `/resources/#sources` を `/resources/sources/` にする。

## 対象外

- ミニアプリ各ページの中身、ResourceCards の見た目、資料データ（取り組み YAML の resources）は変えない。
