# プライバシーポリシー 設計

日付: 2026-10-03

## 目的

お問い合わせと後援会入会申し込みで個人情報を集めるようになったので、その扱いを説明するページを置く。あわせて、導入予定の Google アナリティクス 4（GA4）の読み込みを、測定 ID を設定したときだけ有効になる形で入れる。

## 前提

- サイトの運営名義は「森山貴士後援会」（フッターの © 表記と同じ）。ポリシーでは「当会」と呼ぶ。
- 集める個人情報: お問い合わせ（お名前・メールアドレス・電話番号・件名・内容）、後援会入会申し込み（氏名・ふりがな・郵便番号・住所・電話番号・メールアドレス）。
- 外部サービス: Resend（メール送信）、Cloudflare Turnstile（迷惑投稿対策。送信時に接続情報を Cloudflare が受け取る）、Vercel（ホスティング。アクセスログ）、Google Fonts（フォント配信）、GA4（アクセス解析。導入予定）。
- 連絡先はお問い合わせフォームを案内し、メールアドレスは載せない。
- 後援会入会で集めた情報は、入会の手続きのほか、活動報告や集まりの案内の送付（郵送・メール）にも使うと明記する。

## 方針

- 文章は法律用語を並べず、このサイトで実際にしていることだけを書く。外部サービスの内部の仕組みは断定せず、各社の説明へのリンクを置く。
- 本人の確認は「森山本人」ではなく「当会」が行うと書く（名義に合わせる）。
- 制定日を書き、改定したら日付を更新する。

## ページ: `/privacy/`（`src/pages/privacy.astro`）

下層ページの型（パンくず、`page-hero`、`page-body` に `Toc` と `prose`、最後に `CtaBar`）。メニューには載せず、フッターと各フォームからリンクする。

章立て:

1. **はじめに** (`#intro`): 運営名義と、このページが何を説明するか。
2. **集める情報** (`#collect`): フォームの項目（お問い合わせ・入会申し込みそれぞれ）、送信時に Turnstile が受け取る接続情報、サーバーのアクセスログ、GA4 の計測情報。
3. **利用目的** (`#purpose`): お問い合わせへの返信と連絡。入会の手続き、活動報告や集まりの案内の送付（郵送・メール）。サイトの改善（アクセス解析）。目的の範囲を超えて使わない。
4. **第三者への提供** (`#third-party`): 本人の同意なく第三者に提供しない。法令に基づく場合を除く。
5. **利用している外部サービス** (`#services`): Resend、Cloudflare Turnstile、Vercel、Google アナリティクス 4、Google Fonts。それぞれ何のために使い、何が送られるかを一行で書き、各社のポリシーへリンクする。GA4 は Cookie を使うこと、無効化の方法（Google アナリティクス オプトアウト アドオン）を書く。
6. **保管と削除** (`#retention`): 目的に必要な期間だけ保管し、不要になったら削除する。
7. **開示・訂正・削除の求め** (`#request`): お問い合わせフォームから申し出る。本人確認のうえ対応する。
8. **改定** (`#revision`): 改定したときはこのページで知らせる。制定日 2026年10月3日。

## リンク

- `src/data/site.ts` に `PRIVACY = { label: 'プライバシーポリシー', href: '/privacy/' }` を追加（メニューの `NAV` には入れない）。
- `src/components/layout/SiteFooter.astro` の下段にリンクを置く。
- 各フォーム（`ContactForm.astro`）の一文を種類ごとの文言にし、末尾に「くわしくはプライバシーポリシーをご覧ください」のリンクを付ける。文言は `src/data/contact.ts` に置く（お問い合わせ: 返信と連絡のためだけに使う。入会: 入会の手続きと、活動報告や集まりの案内に使う）。

## GA4 の読み込み

- `astro.config.mjs` の `env.schema` に `GA_MEASUREMENT_ID`（client・public・optional）を追加。
- `src/layouts/Base.astro` の `<head>` で、`GA_MEASUREMENT_ID` があるときだけ Google タグ（`gtag.js`）を読み込む。未設定なら何も出さない。
- `.env.example` と README に変数を書く。Vercel の Production にだけ設定することを README に書く。

## テスト・確認

- `npm run build` が通り、`/privacy/` が出力されること。
- 開発サーバーで、フッターとフォームからページへ遷移できること、目次が各章に飛ぶこと、スマホ幅で横にはみ出さないこと。
- `.env` に `GA_MEASUREMENT_ID` を入れた場合と入れない場合で、`<head>` に gtag のスクリプトが出る・出ないこと。

## やらないこと

- Cookie 同意バナー（GA4 だけなら、ポリシーに記載と無効化方法を書くにとどめる）。
- 英語版。
