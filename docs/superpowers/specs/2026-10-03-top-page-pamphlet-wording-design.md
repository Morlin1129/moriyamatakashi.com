# トップページの文言をパンフレットに揃える 設計書

作成日: 2026-10-03

## 目的

後援会の政策パンフレット（B4二つ折り、初稿）の表現を基準にして、サイトの文言を揃えていく。その第一歩として、トップページの文言をパンフレットに合わせる。セクション構成は変えない。

## パンフレットとトップページのズレ

- ヒーロー: キャッチは同じだが、添え文が違う。パンフレットは「南相馬で暮らし、働き、地域の活動に関わってきました。みんなの声を聞いて、できるところから変えていきます。」
- 取り組み5つ: 並び順は一致。見出しがサイトの `badge`（「職員が成長・活躍できる市役所にする」など）で、パンフレットは短い見出し（「良い地域は良い市役所から」など）と一文のサブ見出し。全体見出し「みんなの『こうしてほしい』が、ちゃんと届くまちへ」もサイトにない。
- 進め方3ステップ: サイトは「今をちゃんと知る／橋渡しをする／手を動かす」、パンフレットは「話を聞く・知る／一緒に考える／手を動かす」。
- 問い合わせ: サイト「話を聞かせてください。」、パンフレット「暮らしの声を、聞かせてください。」
- 「まちで聞いた声」はパンフレットにないが、トップには残す。

## 変更内容

### 1. ヒーロー（`src/components/home/Hero.astro`）

- 見出し: 「こうなったらいいな」／を、ひとつずつ。（パンフレットの表紙と同じ改行位置。読点を1行目に足すとスマホ幅で「を、」だけが折り返したため、改行位置ごと合わせた）
- 添え文: 「南相馬で暮らし、働き、地域の活動に関わってきました。」「みんなの声を聞いて、できるところから変えていきます。」の2行
- 名前行・ボタン・写真は変えない

### 2. まちで聞いた声（`src/components/home/Voices.astro`）

変更なし。

### 3. 取り組み5つ（`src/components/home/Policies.astro`、`src/content/policies/*.yaml`）

- 見出しを「そのためにやりたいこと」から、小見出し「取り組みたいこと」＋見出し「みんなの『こうしてほしい』が、ちゃんと届くまちへ」にする。小見出しは「まちで聞いた声」と同じ eyebrow の見た目にする。
- 各 YAML の `badge` と `plain` を次のとおり書き換える。`badge` はパンくず（取り組みページ）と資料集の絞り込みチップにも使われているので、そこも同時に変わる。これは意図した変更とする。

| order | id | badge | plain |
|---|---|---|---|
| 1 | city-hall | 良い地域は良い市役所から | 市役所の仕事をしやすくし、仕事の質を高めます |
| 2 | children | 子育てしたいと思えるまちへ | 充実した制度に加え、毎日の「ちょっと困る」を減らします |
| 3 | economy | 地元の会社が育つまちへ | 地域で頑張っている会社が成長できるよう応援します |
| 4 | odaka-kashima | みんなの声がちゃんと届く市政へ | 「話を聞きました」で終わらせないようにします |
| 5 | future | 将来も豊かさが続くまちへ | 10年後・20年後にかかるお金まで考えます |

- 注意: odaka-kashima の取り組みページは小高・鹿島に絞った内容で、パンくずとチップの「みんなの声がちゃんと届く市政へ」より狭い。今回はそのままにする。
- `title`・`titleLines`・`lead`・`policyName` は変えない。

### 4. 進め方3ステップ（`src/components/home/Process.astro`）

- 見出し「どうやって進めるの？」は入口ページらしい問いかけとして残す。
- ステップを次に差し替える。

| 番号 | 見出し | 本文 |
|---|---|---|
| 1 | 話を聞く・知る | 困っている人の話を聞いて、数字や資料も調べます。 |
| 2 | 一緒に考える | 市民、会社、市役所。立場をこえて一緒に考えます。 |
| 3 | 手を動かす | 提案するだけでなく、自分にできることは自分でもやります。 |

- 各ステップの上にある小さな補足（「情報をあつめてオープンにする」など）はパンフレットにないので、文言と `.eyebrow` のスタイルごと外す。
- 「くわしい考え方 →」のリンクは残す。

### 5. 問い合わせ（`src/components/home/ContactStrip.astro`）

- 見出しを「暮らしの声を、聞かせてください。」にする。手書き風の添え書きとボタンは変えない。

## 今回やらないこと

- `/vision/` の「大切にする、3つの進め方」はそのまま。トップとのズレは次の課題にする。
- 各取り組みページの本文や、パンフレットの小タグ（「会議や調整にかかる時間を減らす」など）の反映。
- ヒーローへの4タグ（移住して12年／IT・業務改善／地域拠点を運営／子育て中）の追加。
- プロフィールページの文言。

## 確認方法

- nodebrew の v22.20.0 を PATH に通して `npm run build` が通ること。
- 1280px と 375px でトップを表示し、5セクションの文言が上記のとおりで、コンソールにエラーがないこと。
- `/policies/city-hall/` などのパンくずと、`/resources/sources/` のチップが新しい `badge` になっていること。
